# Archived: the Rynko commercial-layer notes

These three notes (April–May 2026) described a commercial platform, "Rynko", that would have sat
above the open-source framework — hosted tracing, approval gates, a market analysis. None of it was
built or deployed, and SwarmKit itself now covers what the notes reserved for it: funnels and
multi-party approval for gates, OpenTelemetry to any collector for tracing, the self-hosted fleet
control plane for operations. They are kept here as history only; nothing current refers to them.
